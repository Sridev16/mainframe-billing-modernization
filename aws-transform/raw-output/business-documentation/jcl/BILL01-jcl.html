Summary

The JCL job BILL01 executes the BILLING program to perform monthly billing processing for customers. It reads customer and usage data from legacy billing files and generates or updates invoice records based on the consumption data. ### Key Functionalities: - Reads customer account information from the legacy billing customer file to identify accounts subject to monthly billing - Reads usage data from the legacy billing usage file to determine consumption amounts for each customer - Writes or updates invoice records to the legacy billing invoice file based on customer usage, producing the monthly billing output

Dataset Information (3)

Dataset/Table Name Type Usage
LEGACY.BILLING.CUSTOMER SEQUENTIAL Input file containing customer account information; opened for shared read access, allowing concurrent access by other jobs
LEGACY.BILLING.USAGE SEQUENTIAL Input file containing customer usage/consumption data for the billing period; opened for shared read access, allowing concurrent access by other jobs
LEGACY.BILLING.INVOICE SEQUENTIAL Output file where invoice records are written or updated; opened with exclusive access (OLD disposition), preventing other jobs from accessing it during processing
